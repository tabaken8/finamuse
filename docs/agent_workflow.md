# エージェント作業ワークフロー概要

このリポジトリでは、エージェントが以下のようなタスクを組み合わせて作業できます。

## ディレクトリ構造の調整
- 既存フォルダの整理や新規ディレクトリの追加
- ファイルの移動、名称変更、不要ファイルの削除
- コード分割のためのサブディレクトリ作成

## ファイル操作
- 新規ファイルの追加（コンポーネント、ユーティリティ、設定ファイルなど）
- 既存ファイルの編集やリファクタリング
- コードの一部を別ファイルへ切り出して再利用する構造変更

## ブランチ運用
- `git checkout -b <branch>` で作業用ブランチを作成
- 作業内容をコミットし、必要に応じて PR を作成

これらの手順により、ディレクトリ構造のブラッシュアップやコードの再配置といったタスクにも対応できます。
